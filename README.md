
# 📱 Telefonchiki

## 📝 Описание проекта
Telefonchiki — это проект на Python, который использует нейронную сеть для классификации изображений. Программа анализирует загруженную картинку и определяет, к какому классу она относится.

## 🛠 Технологии
- Python
- TensorFlow / Keras — для работы с нейронной сетью
- OpenCV — для обработки изображений
- Pillow (PIL) — для открытия и проверки изображений
- Matplotlib — для отображения результатов

## ⚙️ Функционал
- Проверка существования файла изображения.
- Проверка изображения на повреждения.
- Изменение размера изображения до 128 × 128 пикселей.
- Нормализация значений пикселей.
- Классификация изображения с помощью обученной модели.
- Вывод предсказанного класса.
- Отображение изображения с результатом распознавания.

## 📂 Структура проекта
- `dataset/` — папка с изображениями для классов.
- `image_classifier.h5` — обученная модель нейронной сети.
- `ecranchiki_test.py` — скрипт для проверки и классификации изображений.
- `ecranchiki_training.py` — скрипт обучения модели.

## 🚀 Запуск проекта
1. Установите необходимые библиотеки:
   ```bash
   pip install tensorflow opencv-python pillow matplotlib
   ```
2. Подготовьте папку `dataset/` с изображениями.
3. Поместите обученную модель `image_classifier.h5` в папку проекта.
4. Запустите скрипт:
   ```bash
   python ecranchiki_test.py
   ```
